Systems Integrity & Guardrail Architecture

ENGINE DIRECTIVE // ZERO-HALLUCINATION POLICY

Source-Driven Archetypes (Autonomous AST Extraction)

Categories like CAT.01 (Feature Shipped), CAT.02 (Improvement), and CAT.08 (Behind the Scenes) execute autonomously by parsing commit histories, merged GitHub PRs, changed file paths, and CI/CD configuration files. They surface stories automatically whenever git HEAD advances with valid semantic commits.

Context-Augmented Archetypes (Builder Prompted)

Categories like CAT.07 (Failed Experiment), CAT.10 (Problem & Solution), and CAT.16 (Founder Reflection) deliberately require human insight. Releasebuff will never infer internal emotional states or invent speculative motivations from silent commit diffs.
